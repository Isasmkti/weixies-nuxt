# Web Visual Design Skill

A framework-agnostic `SKILL.md` for coding agents that create or refine web interfaces.

## Install

Copy the `web-visual-design` folder into the skills directory supported by your agent. Common project-local locations include:

- `.agents/skills/web-visual-design/`
- `.claude/skills/web-visual-design/`

Use the location documented by your specific agent. Keep `SKILL.md` at the root of the skill folder.

## Use

Ask your agent to apply the `web-visual-design` skill when creating or redesigning a page. The skill instructs the agent to inspect the repository and preserve its existing product identity; it does not impose a preset color palette or framework.
